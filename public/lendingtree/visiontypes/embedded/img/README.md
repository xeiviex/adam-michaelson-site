# Photos for the embedded visiontype

One file per slot. To replace a photo, save the new one over the old file with the same name and shape (3:2, landscape).
The listing data that points at these files is in `../data.js` (`LISTINGS`).

The photos are AI-generated illustrations of one truck in one setting, not photographs of a real vehicle for sale.
The gallery set is 1264 x 848. Each was checked for distortions, licence plates and stray text before use.
